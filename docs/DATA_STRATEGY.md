## 一、結論先行

本專案的資料需求可分三層，目前只有第一層經實測確認可自動取得：

| 層 | 來源 | 取得方式 | 涵蓋範圍 | 狀態 |
|---|---|---|---|---|
| **第 1 層：法規原文** | 全國法規資料庫 API | 自動（curl 即可，免金鑰） | 資格條件、金額公式、期限、併領限制 | ✅ 可用 |
| **第 2 層：行政計畫** | 台灣就業通、勞動部官網 | 手動整理 | 產業新尖兵、微型創業鳳凰、課程等 | ⚠️ 需人工 |
| **第 3 層：即時資訊** | Exa AI MCP | Agent 即時搜尋 | 職缺趨勢、最新開課、新聞 | ✅ 已整合 |

## 二、各層詳細說明

### 第 1 層：法規原文（自動、權威、可引用）

**資料源**：`https://law.moj.gov.tw/api/Ch/Law/JSON` 和 `https://law.moj.gov.tw/api/Ch/Order/JSON`

**特性**：
- 免申請、免金鑰、免認證
- 回傳 ZIP 檔，內含完整 JSON（法律 1,336 筆 + 命令 10,440 筆）
- 每筆含：法規名稱、條號、條文全文、官方網址、修正日期
- 更新頻率：約每週（實測資料日期 2026/7/17）

**能直接用在專案的法規**：

| 法規名稱 | 類型 | 修正日 | 條文數 | 對應功能 |
|---|---|---|---|---|
| 就業保險法 | 法律 | 2022-01-12 | 55 | 失業給付、提早就業獎助、職訓生活津貼、育嬰津貼 |
| 就業服務法 | 法律 | 2025-01-20 | 92 | 就業服務站職責、求職登記 |
| 職業訓練法 | 法律 | 2015-07-01 | 64 | 訓練機構分類 |
| 中高齡者及高齡者就業促進法 | 法律 | 2024-07-31 | 54 | 中高齡就業獎勵依據 |
| 就業促進津貼實施辦法 | 命令 | 2025-09-01 | 40 | 求職交通補助、臨時工作津貼、職訓津貼（非就保身分） |
| 就業保險促進就業實施辦法 | 命令 | 2025-07-17 | 79 | 僱用獎助、異地就業交通/租屋/搬遷補助 |
| 失業中高齡者及高齡者就業促進辦法 | 命令 | 2025-04-28 | 57 | 中高齡創業貸款、僱用獎助 |
| 就業保險失業者創業協助辦法 | 命令 | 2026-06-10 | 33 | 創業貸款 200 萬、利息補貼 |
| 身心障礙者職務再設計實施方式及補助準則 | 命令 | 2016-05-25 | 19 | 職務再設計補助 |
| 育嬰留職停薪實施辦法 | 命令 | 2025-11-21 | 9 | 育嬰留停程序 |

**使用方式**：
1. 下載 ZIP → 解壓 JSON → 依法規名稱篩選相關法條
2. 從條文中用 regex 或 LLM 萃取：資格條件、金額公式、期限上限
3. 結構化後寫入 `resources.json`，並附 `law_reference` 欄位（條號 + URL）

**限制**：
- 法規只定義「規則」，不含「去哪辦」（承辦地點）、「目前有什麼課」（動態課程）
- 金額若以「最低工資」為基準，法規不會寫死數字，需另外查當年度公告值
- 部分補助（產業新尖兵）屬年度計畫，不在法規資料庫裡

### 第 2 層：行政計畫與方案細節（手動整理）

這些資訊散落在各級機關網站，無統一 API，需人工查閱後結構化：

| 項目 | 來源網站 | 要取的資料 |
|---|---|---|
| 產業新尖兵計畫 | `www.taiwanjobs.gov.tw` | 課程類型、報名方式、資格、補助內容 |
| 微型創業鳳凰貸款 | `beboss.wda.gov.tw` | 貸款額度、利率、對象、申請流程 |
| 職務再設計補助金額 | `www.wda.gov.tw` 年度公告 | 補助上限（法規未寫死） |
| 就業服務站清單 | `job.taiwanjobs.gov.tw` | 站點、地址、電話 |
| 當年度最低工資 | 勞動部公告 | 數字（2026 年為 28,590 元/月） |
| 職前訓練課程 | 台灣就業通 | 課程名稱、期間、地點、報名截止 |

**建議整理方式**：
- 每筆寫成 `resources.json` 的一個 entry
- 必須標註 `source_url` 和 `last_verified`（人工確認日期）
- 比賽前目標：10~15 筆

**為什麼無法自動化**：
- `data.gov.tw` API 需申請 Authorization Key（實測確認）
- 台灣就業通無公開 API、頁面用 Big5 編碼且結構不穩定
- 各計畫每年度內容可能微調

## 五、關鍵決策紀錄

| 決策 | 原因 |
|---|---|
| 不接 data.gov.tw API | 需申請 key，流程不確定，比賽時間壓力下不值得 |
| 法規 API 作為第 1 層主要來源 | 免金鑰、權威、含條號可引用、評分加分 |
| 第 2 層手動整理而非爬取 | 來源網站不穩定、Big5 編碼、結構常變，手動整理更可靠 |
| 保留 Exa MCP 作為第 3 層 | 已整合、零成本、能補動態資訊缺口 |
| resources.json 維持靜態檔 | 比賽帳號無 DynamoDB，且靜態檔隨部署打包，零額外依賴 |

## 六、風險與緩解

| 風險 | 影響 | 緩解 |
|---|---|---|
| 法規 API 比賽當天掛了 | 無法重新產生 resources.json | 事先產好 JSON 打包進部署，不依賴即時抓取 |
| 手動整理的資料過時 | 金額或條件不準確 | 標 `last_verified` + 每筆附 source_url |
| Exa MCP 回傳不相關結果 | Agent 回覆品質下降 | 加 graceful degradation：搜尋失敗時改用靜態資料回覆 |
| 最低工資數字年度更新 | 金額試算不準 | 獨立欄位存放，每年更新一次即可 |
