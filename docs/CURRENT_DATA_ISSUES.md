# 職涯導航家 — 現有 resources.json 資料錯誤勘誤表

> 最後更新：2026-07-29
> 對照來源：全國法規資料庫 API 實測取得之法條原文（2026/7/17 版）

## 總覽

現有 `app/career_navigator/data/resources.json` 共 8 筆資料，其中 **6 筆有實質錯誤**，2 筆無法從法規確認（來源為行政計畫）。

| ID | 名稱 | 錯誤嚴重度 | 類型 |
|---|---|---|---|
| `unemployment_benefit` | 失業給付 | 🔴 高 | 資格條件錯、期限不完整、缺加給 |
| `training_living_allowance` | 職業訓練生活津貼 | 🔴 高 | 描述有法律錯誤（「可併行申請」） |
| `employment_promotion_allowance` | 就業促進津貼（求職交通補助） | 🟡 中 | 金額錯誤 |
| `mid_age_employment_subsidy` | 中高齡就業促進獎勵 | 🔴 高 | 金額無出處、對象搞混（雇主vs勞工） |
| `skill_upgrade_program` | 產業新尖兵計畫 | ⚪ 無法驗證 | 行政計畫，非法規（無法從API驗證） |
| `self_employment_startup_subsidy` | 微型創業鳳凰貸款 | 🟡 中 | 名稱與內容混淆兩個不同方案 |
| `childcare_reemployment_subsidy` | 婦女再就業托育津貼 | ⚪ 無法驗證 | 行政計畫，非法規 |
| `disability_employment_subsidy` | 身心障礙者職務再設計補助 | 🟡 中 | 金額「最高10萬」無法規依據 |

## 逐筆勘誤

### 1. `unemployment_benefit` — 失業給付 🔴

**現有內容**：
```json
{
  "min_insurance_months": 1,
  "monthly_amount_formula": "avg_insured_salary * 0.6",
  "max_months": 6,
  "description": "...可請領月投保薪資 60% 之失業給付，最長 6 個月。"
}
```

**錯誤清單**：

| # | 錯誤欄位 | 現有值 | 正確值 | 法規依據 |
|---|----------|--------|--------|----------|
| 1 | `min_insurance_months` | 1 | **12**（前3年內年資合計滿1年） | 就業保險法 §11-1 |
| 2 | `max_months` | 6（唯一值） | **6 或 9**（45歲↑或身障→9月） | 就業保險法 §16-1 |
| 3 | 缺欄位 | — | **眷屬加給 10%/人，上限 20%** | 就業保險法 §19-1 |
| 4 | 缺欄位 | — | **需向就服站辦理求職登記後 14 日** | 就業保險法 §11-1 |
| 5 | `description` | 「有勞保投保年資」 | 「就業保險年資」（勞保≠就保） | 就業保險法 §11 |

**影響**：`min_insurance_months: 1` 會讓只保1個月的人被判定「符合資格」，實際上他們不符合。45歲以上使用者被告知最多6個月，少領3個月的錢。

### 2. `training_living_allowance` — 職業訓練生活津貼 🔴

**現有內容**：
```json
{
  "monthly_amount_formula": "avg_insured_salary * 0.6",
  "max_months": 6,
  "description": "...可加領訓練生活津貼...可與失業給付併行申請不同期間。"
}
```

**錯誤清單**：

| # | 錯誤 | 說明 | 法規依據 |
|---|------|------|----------|
| 1 | 描述「可與失業給付併行申請」 | **錯！** 法規明確規定「領取失業給付期間，**不得同時**請領職業訓練生活津貼」 | 就業促進津貼實施辦法 §26-3 |
| 2 | 金額公式只有一種 | 實際有**兩套制度**：(A) 就保身分→平均月投保薪資×60%；(B) 非就保身分（就促津貼辦法）→最低工資×60% | 就業保險法 §19-2 vs 就業促進津貼實施辦法 §20 |
| 3 | max_months 只有 6 | 身障者最長 **1 年** | 就業促進津貼實施辦法 §20 |
| 4 | 缺「全日制」定義 | 需符合：每週4日↑、每日4hr↑、每月100hr↑、期間1月↑ | 就業促進津貼實施辦法 §18-2 |

**影響**：描述中的「可併行」會讓使用者以為能同時領失業給付+職訓津貼，實際上會被追回溢領。這是最嚴重的錯誤 — 可能導致使用者做出錯誤財務決定。

---

### 3. `employment_promotion_allowance` — 求職交通補助 🟡

**現有內容**：
```json
{
  "monthly_amount_formula": "flat:1500",
  "max_months": 3,
  "description": "...每次最高 1,500 元，每年最多 4 次。"
}
```

**錯誤清單**：

| # | 錯誤欄位 | 現有值 | 正確值 | 法規依據 |
|---|----------|--------|--------|----------|
| 1 | `flat:1500` | 1,500 元 | **500 元**（特殊情形核實最高 1,250 元） | 就業促進津貼實施辦法 §8 |
| 2 | `max_months: 3` | 3 個月 | 不適用月概念，是**每年度 4 次** | 就業促進津貼實施辦法 §8-2 |
| 3 | 描述 | 「每次最高 1,500 元」 | 每次 500 元，特殊情形不超過 1,250 元 | 就業促進津貼實施辦法 §8-1 |

**影響**：金額膨脹 3 倍，使用者期待落空。雖然金額小，但會損害 Agent 可信度。

---

### 4. `mid_age_employment_subsidy` — 中高齡就業促進獎勵 🔴

**現有內容**：
```json
{
  "min_age": 45,
  "monthly_amount_formula": "flat:5000",
  "max_months": 12,
  "description": "45 歲以上失業者受僱且穩定就業滿一定期間，可申請就業獎勵，最長 12 個月。"
}
```

**錯誤清單**：

| # | 錯誤 | 說明 | 法規依據 |
|---|------|------|----------|
| 1 | 金額 5,000 元 | **查無此金額出處**。法規中的金額是 13,000/15,000 元 | — |
| 2 | 發給對象隱含「勞工」 | **實際是發給雇主！** 法規名稱為「僱用獎助」，是雇主僱用特定對象後向就服站申請的獎勵 | 失業中高齡就業促進辦法 §41 |
| 3 | 描述寫「可申請就業獎勵」 | 暗示勞工自己可申請，但這是雇主才能申請的 | 同上 |

**影響**：這是最嚴重的概念錯誤。使用者會以為自己能領每月 5,000 元，實際上：(1) 金額不對；(2) 根本不是給勞工的，是給雇主的僱用誘因。如果 Agent 這樣告訴使用者，使用者去就服站問會被打臉，Agent 可信度全毀。

**正確資訊**：
- 雇主僱用中高齡者（45-64）全時：每月 13,000 元
- 雇主僱用高齡者（65↑）全時：每月 15,000 元
- 最長 12 個月
- 此筆應標為 `recipient: "雇主"`，或拆成「對勞工說明：你的雇主可以因為僱用你而獲得獎勵，這增加你被錄用的機會」

### 5. `skill_upgrade_program` — 產業新尖兵計畫 ⚪

**現有內容**：
```json
{
  "requires_skill_gap": true,
  "monthly_amount_formula": "flat:0",
  "max_months": 6,
  "description": "...提供免費數位/AI應用職訓課程..."
}
```

**評估**：
- 此方案屬行政計畫（年度預算執行），不在法規資料庫裡
- 無法從 API 驗證金額或資格
- `requires_skill_gap: true` 這個條件在程式碼中等同於 `wants_training`，邏輯正確但命名不精確
- 建議保留但標註 `source_url` 和 `last_verified`

### 6. `self_employment_startup_subsidy` — 微型創業鳳凰貸款 🟡

**現有內容**：
```json
{
  "min_age": 20,
  "requires_business_plan": true,
  "monthly_amount_formula": "flat:0",
  "description": "45 歲以上婦女或中高齡者自行創業，可申請最高 200 萬元創業貸款，前 3 年利息減半。"
}
```

**錯誤清單**：

| # | 錯誤 | 說明 | 法規依據 |
|---|------|------|----------|
| 1 | 名稱寫「微型創業鳳凰」 | 但描述中的 200 萬和利率條件實際對應的是**就業保險失業者創業協助辦法**（就保創業貸款），不是微型創業鳳凰 | 就業保險失業者創業協助辦法 §7, §11 |
| 2 | 「前 3 年利息減半」 | **錯！** 前 3 年是**全額補貼**（不是減半），第 4 年起超過 1.5% 才由政府補差額 | 就業保險失業者創業協助辦法 §11 |
| 3 | `min_age: 20` | 就保創業貸款無年齡下限（有就保身分即可）。微型創業鳳凰主要對象才是「45歲以上婦女」 | — |
| 4 | 混淆兩個方案 | 「微型創業鳳凰」和「就保失業者創業貸款」是兩個不同方案，資格和條件不同 | — |

**影響**：使用者搞不清楚自己該申請哪一個，且利率描述錯誤會讓人低估實際利息負擔。

---

### 7. `childcare_reemployment_subsidy` — 婦女再就業托育津貼 ⚪

**現有內容**：
```json
{
  "requires_childcare": true,
  "monthly_amount_formula": "flat:3000",
  "max_months": 6,
  "description": "育有 12 歲以下子女之再就業婦女，可申請托育津貼..."
}
```

**評估**：
- 在法規資料庫中搜尋「婦女再就業」「托育津貼」均無直接對應法規
- 可能來自地方政府計畫或已結束的中央計畫
- **需人工查證來源**，若確認無依據應移除或標註為「地方方案，限特定縣市」
- 注意：不要跟「育嬰留職停薪津貼」（就保法 §19-2，投保薪資60%）搞混

### 8. `disability_employment_subsidy` — 身心障礙者職務再設計補助 🟡

**現有內容**：
```json
{
  "requires_disability_cert": true,
  "monthly_amount_formula": "flat:0",
  "description": "...最高補助 10 萬元。"
}
```

**錯誤清單**：

| # | 錯誤 | 說明 | 法規依據 |
|---|------|------|----------|
| 1 | 「最高 10 萬元」 | 法規（身心障礙者職務再設計實施方式及補助準則）中**未明訂金額上限**，10 萬元可能來自年度計畫公告 | 補助準則全文 |
| 2 | 缺「誰申請」 | 職務再設計是**雇主**為身障員工申請的設備/環境改善補助，不是身障者自己申請 | 補助準則 §1, §3 |
| 3 | 描述不完整 | 未提及補助範圍：輔具、工作設備、環境改善、就業輔導人員 | — |

**影響**：同 #4 的問題 — 使用者以為自己能申請，其實是雇主才能申請的。
